À faire avant la séance

Installer et configurer son environnement

Compter 20 à 30 minutes. Ces étapes sont individuelles : chacun·e des deux membres du binôme doit les avoir terminées de son côté.

1. Installer Git

Télécharger et installer Git pour votre système :

  • Windows : git-scm.com (garder les options par défaut de l'installeur).
  • macOS : ouvrir un terminal et taper git --version ; si Git n'est pas installé, macOS propose d'installer les outils en ligne de commande Xcode.
  • Linux : sudo apt install git (Debian/Ubuntu) ou l'équivalent de votre distribution.

Vérifier l'installation dans un terminal :

git --version

2. Se présenter à Git

Git attribue chaque commit à une identité. Sans configuration, les commits du binôme risquent d'apparaître sous un nom générique ou erroné : 

git config --global user.name "Prénom Nom"
git config --global user.email "adresse@exemple.fr"

Utilisez de préférence l'adresse associée à votre compte GitHub, pour que vos commits soient bien liés à votre profil.

3. Créer un compte GitHub

Si ce n'est pas déjà fait, créer un compte gratuit sur github.com/join. Notez votre identifiant GitHub exact : votre binôme en aura besoin pour vous ajouter comme collaborateur (scénario 1).

4. Installer VSCode et les extensions utiles

Télécharger VSCode sur code.visualstudio.com, puis installer deux extensions depuis le panneau Extensions (icône en forme de blocs, ou Ctrl+Shift+X) :

  • GitHub Pull Requests and Issues (éditeur officiel GitHub) - permet de créer et relire des Pull Requests sans quitter VSCode.
  • GitLens (optionnel mais recommandé) - enrichit l'historique et affiche l'auteur de chaque ligne.

5. Connecter VSCode à GitHub

Dans VSCode, ouvrir la palette de commandes (Ctrl/Cmd+Shift+P), taper GitHub: Sign in et suivre le parcours d'authentification dans le navigateur. Une icône de compte doit apparaître en bas à gauche de VSCode une fois connecté·e.

Si l'authentification par navigateur ne fonctionne pas

Sur les postes de la salle où le navigateur par défaut est restreint, utilisez un Personal Access Token (Settings > Developer settings > Personal access tokens sur github.com) comme mot de passe lors du premier git push.

Checklist avant la séance

  • ☐ git --version répond sans erreur.
  • ☐ git config --global user.name et user.email sont corrects.
  • ☐ Compte GitHub créé, identifiant noté.
  • ☐ VSCode installé avec l'extension GitHub Pull Requests and Issues.
  • ☐ VSCode connecté à mon compte GitHub.
