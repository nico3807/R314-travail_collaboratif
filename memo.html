Aide-mémoire

Commandes Git et raccourcis VSCode

À garder ouvert dans un onglet pendant les scénarios.

Commandes Git essentielles

Commande À quoi elle sert
git init Transforme le dossier courant en dépôt Git.
git clone <url> Copie un dépôt distant en local, avec tout son historique.
git status Affiche l'état des fichiers (modifiés, en staging, suivis ou non).
git add <fichier> Place un fichier dans la zone de staging.
git commit -m "message" Enregistre une nouvelle photographie du projet dans l'historique local.
git push Envoie les commits locaux vers le dépôt distant.
git pull Récupère les commits distants et les fusionne dans la branche locale.
git log --oneline --graph --all Visualise l'historique et ses éventuelles branches sous forme condensée.
git branch Liste les branches locales.
git checkout -b nom-de-branche Crée une nouvelle branche et bascule dessus.
git push -u origin nom-de-branche Publie une branche locale sur le dépôt distant pour la première fois.
git diff Affiche les différences non encore stagées.
git revert <hash> Annule un commit en ajoutant un nouveau commit inverse (sûr sur un historique partagé).
git rm --cached <fichier> Retire un fichier du suivi Git sans le supprimer du disque.

Commande à éviter en binôme

git reset --hard et git push --force réécrivent l'historique. Sur un dépôt déjà partagé, cela peut faire disparaître le travail de l'autre. On les réserve à un historique strictement local et non encore poussé.

VSCode : où cliquer

Action Où / raccourci
Ouvrir le panneau Source Control Ctrl/Cmd+Shift+G, ou l'icône de branche dans la barre latérale.
Ouvrir la palette de commandes Ctrl/Cmd+Shift+P
Cloner un dépôt Palette de commandes > Git: Clone
Stage un fichier Cliquer sur le « + » à côté du fichier dans Source Control
Changer de branche Nom de la branche en bas à gauche de la fenêtre
Résoudre un conflit Cliquer sur le fichier en conflit ; utiliser les boutons « Accepter la version actuelle / entrante / les deux »
Ouvrir une Pull Request Onglet « Pull Requests » (icône GitHub) ajouté par l'extension GitHub Pull Requests and Issues
Voir qui a modifié une ligne Extension GitLens, annotations en fin de ligne

Convention de message de commit conseillée

Un verbe à l'infinitif suivi d'un résumé court, en français ou en anglais mais de façon cohérente pour tout le binôme : 

Ajoute la page mentions légales
Corrige le lien vers la page contact
Retire un fichier indésirable du suivi
